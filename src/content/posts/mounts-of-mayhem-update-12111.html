Hey everyone. The server is now live with 1.21.11, the Mounts of Mayhem game drop! This drop adds spears, a new primary tiered weapon whose damage scales with velocity, and some new mounts, such as the Nautilus. See here for more info.

We've got a few supporting updates for SSS systems:

  • 💀Mob heads are available for the Parched, Camel Husks, and all 3 Nautilus variants.

  • 🥚Mob catching works for Camel Husks and all 3 Nautilus variants, as well as for any pacified mob, such as Shrink Ray victims.

  • 🏒Spears can be enchanted with Extinction, all Aspects, Bounty Hunter, Soulbound, Unbreaking IV, and weaponry curses like Bloodletting.

  • ⚽Maces can now be enchanted with Bounty Hunter.

  • 💾`/lexicon by_item` allows searching by `spears` and also now by `shovels`, which was missing previously.

  • 💾 `/valor` has improved click-based navigation in its interfaces.

Let us know if you run into any issues. Cheers and Happy New Year! 🫶 🎇
