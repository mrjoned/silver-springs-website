🎃Spooky Springs Poll

For the uninitiated, Spooky Springs is a special build contest we sometimes run near Halloween where each group builds in separate plots in a shared Halloween town. This gives you limited space to work with, but everyone gets to build near each other. To see some examples, check the `SpookySprings2017`, `SpookySprings2019`, and `SpookySprings2023` warps.

This year, we'd like to gauge what you're all most interested in: the typical plot-based format, a more classic build contest in the survival world, or something else. Use the poll here and share any additional feedback here. Thanks!
